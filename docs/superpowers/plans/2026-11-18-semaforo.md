# Semáforo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dedicated Semáforo module to the local LegalRun replica, using the existing activity-priority data to show actionable case status at a glance.

**Architecture:** Keep the current hash-routed React app and existing backend endpoint `GET /api/dashboards/activity`. Add a small tested helper for bucket/summary logic, then render a dedicated `SemaforoPage` inside the current app shell and wire it into navigation.

**Tech Stack:** React 19, TypeScript, Vite 6, Vitest, Testing Library, local Node/SQLite backend

**Spec:** `docs/superpowers/specs/2026-11-18-semaforo-design.md`

## Global Constraints

- Remain a local-only replica with no connection to LegalRun real services.
- Use the existing hash router and app shell patterns in `src/App.tsx`.
- Reuse `GET /api/dashboards/activity` instead of introducing a new backend contract in this first slice.
- Avoid broad refactors of `src/App.tsx`; keep changes scoped and consistent with current code style.
- Add Vitest coverage for both the Semáforo logic and the route/page rendering.

## Review Focus

- Empty or sparse activity data should still render KPIs and an empty-state message without crashing.
- Cases with no movements must appear in the `Sin movimientos` bucket and count correctly in summary cards.
- Portfolio filtering from the global topbar must still limit visible Semáforo rows the same way current dashboards do.
- Search and bucket filtering must not hide matching records because of accent/case differences in visible text.
- Exported CSV must reflect the currently filtered Semáforo table, not the full unfiltered dataset.

### Task 1: Add tested Semáforo bucketing helpers

**Files:**
- Create: `src/semaforo.ts`
- Create: `src/semaforo.test.ts`

**Interfaces:**
- Consumes: `ActivityItem`-shaped records with `priority`, `daysWithoutMovement`, `amount`, `state`, `jurisdiction`, `number`, `title`, `lastMovement`
- Produces:
  - `export type SemaforoBucket = "sin-movimientos" | "alta" | "media" | "baja"`
  - `export function toSemaforoBucket(item: { priority: string; daysWithoutMovement: number | null }): SemaforoBucket`
  - `export function buildSemaforoSummary(items: Array<{ priority: string; daysWithoutMovement: number | null }>): { sinMovimientos: number; alta: number; media: number; baja: number; total: number }`
  - `export function filterSemaforoItems<T extends { priority: string; daysWithoutMovement: number | null; amount: string; state: string; jurisdiction: string; number: string; title: string; lastMovement: string }>(items: T[], options: { bucket: "all" | SemaforoBucket; search: string; state?: string; jurisdiction?: string; minAmount?: string }): T[]`

- [ ] **Step 1: Write the failing test**

```ts
import { describe, expect, it } from "vitest";
import { buildSemaforoSummary, filterSemaforoItems, toSemaforoBucket } from "./semaforo";

describe("semaforo helpers", () => {
  it("maps current activity priority rules into UI buckets", () => {
    expect(toSemaforoBucket({ priority: "Sin movimientos", daysWithoutMovement: null })).toBe("sin-movimientos");
    expect(toSemaforoBucket({ priority: "Alta", daysWithoutMovement: 80 })).toBe("alta");
    expect(toSemaforoBucket({ priority: "Media", daysWithoutMovement: 35 })).toBe("media");
    expect(toSemaforoBucket({ priority: "Baja", daysWithoutMovement: 8 })).toBe("baja");
  });

  it("builds summary counts and filters by bucket, search and dashboard filters", () => {
    const items = [
      { priority: "Sin movimientos", daysWithoutMovement: null, amount: "$ 0,00", state: "En trámite", jurisdiction: "Capital", number: "1", title: "Alpha", lastMovement: "Sin movimientos registrados" },
      { priority: "Alta", daysWithoutMovement: 80, amount: "$ 100,00", state: "Pendiente", jurisdiction: "Capital", number: "2", title: "Beta", lastMovement: "Demanda" },
    ];

    expect(buildSemaforoSummary(items)).toEqual({ sinMovimientos: 1, alta: 1, media: 0, baja: 0, total: 2 });
    expect(filterSemaforoItems(items, { bucket: "alta", search: "beta", jurisdiction: "Capital" })).toHaveLength(1);
  });
});
```
